# 테스트 계획

| 대상 | 현재 검증 | 후속 인수 |
|---|---|---|
| FR-03 계산 | 기준 금액, 할인, 반올림, 상세 원가, 0원, 입력 상한, 100행, 결정성 | AT-03 전체 정책·출력 일치 |
| FR-04 승인 | 제출 불변, 승인 전 출력 거부, 반려 | AT-05·06·13 DB/API/E2E |
| FR-06 원가 경계 | 고객 DTO의 허용 필드 | AT-07 실제 PDF/XLSX/HWPX 구조·열기·인쇄 |
| FR-11 권한 | 도메인 액션 거부 | AT-12 인증된 API 우회 공격·세션 |

단위 테스트 통과를 인수 테스트 완료로 간주하지 않는다. AT-01~16은 현재 모두 미완료다. DB 통합 테스트에서는 동시 수정·스냅샷 불변·감사 원자성을 검증하고, E2E에서는 작성→승인→발송→수주→변경계약 흐름을 검증한다. 백업은 격리 환경에서 DB와 파일을 함께 복원해 확인한다.

## 2차 구현의 실행된 통합 검증

PGlite에 실제 SQL 마이그레이션을 적용하고 Better Auth HTTP 핸들러 및 Next.js API 함수를 실행한다. 테스트 DB는 업무 DB와 분리된다.

- 로그인·공개 가입 차단·비로그인/비활성 직원 차단·로그아웃 후 세션 폐기.
- TOTP 등록·확인, 2차 인증 전 API 거부, 복구 코드 로그인, 로그인 요청 횟수 제한.
- 견적 100행 서버 계산·저장·재조회, 조회자 원가 응답 제한·수정 거부.
- Origin 검사·위조 합계 거부·회사 범위·거래처/현장 연결 검증.
- 동시 수정의 단일 성공, 생성/수정 재시도의 중복 방지, 감사 실패 시 롤백.
- 임시 파일 DB를 종료·재개방한 뒤 견적 금액·행 유지.

실제 브라우저 E2E, 운영 PostgreSQL, 전체 제출 승인 흐름 및 백업 복원은 아직 검증하지 않았다.
