# 상태·승인 설계

업무 상태(작성/제출/검토/협상/수주/실주/보류)와 버전 승인 상태는 별도 축이다. 현재 구현은 버전 제출·승인 도메인 규칙만 포함한다.

| 명령 | 전제 | 결과 |
|---|---|---|
| 제출 | 편집 가능한 초안, 제출 권한 | 불변 버전, 승인 필요 시 pending |
| 승인/반려 | 불변 버전, pending, 승인 권한 | approved 또는 rejected, 계속 불변 |
| 고객 출력 | 불변 버전, 승인 또는 면제, 출력 권한 | 출력 허용 |
| 제출본 수정 | 기존 버전 직접 수정 금지 | 새 버전 초안으로 복사, 후속 구현 |

승인 필요 여부는 앞으로 서버가 저장된 정책과 계산 결과로 결정한다. 현재 순수 함수의 boolean을 클라이언트 입력 그대로 신뢰해서는 안 된다. 승인자 지정·자기 승인 정책·첨부 및 조건 변경의 재승인 기준은 구현 전 확정한다.
