# 운영 비용 가정

월 30,000~50,000원은 목표이며 공급자 견적·실제 요금은 미검증이다. 현재 유료 서비스 계약·외부 자격 증명·배포는 없다.

초기 시뮬레이션 입력 가정: 직원 5명, 월 신규 견적 100건, 견적당 평균 3개 버전, 버전당 문서/첨부 평균 5MB, 월 메일 500건. 실제 업무 확인 후 수정한다.

단순 증가 추정: 100×3×5MB=월 약 1.5GB이며, 백업·복제·기존 문서 이관·로그는 별도다. 삭제 없이 1년이면 약 18GB다. 이는 서비스 용량 견적이 아니라 예시 입력값이다.

| 비용 항목 | 비교 시 확인 |
|---|---|
| 앱·작업 실행 | 상시 실행, CPU·메모리, 문서 생성 시간, 예약 작업 |
| PostgreSQL | 최소 고정비, 연결 한도, 저장공간, 자동 백업 |
| 파일 저장 | 원본·버전·출력물·백업 용량, 다운로드 트래픽 |
| 메일·인증 | 발송량, MFA, 도메인 인증 |
| 관측·복구 | 로그 보존, 에러 추적, 별도 백업, 복원 환경 |
| 기타 | 도메인, 환율·부가 비용, 라이브러리 라이선스 |

후속 결정에는 공식 요금표 날짜·환율 가정·기본/증가 사용량·예산 초과 대응을 기록한다. RPO 24시간/RTO 8시간은 제안이며 운영 승인 전 확정값이 아니다.
