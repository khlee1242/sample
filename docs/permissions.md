# 초기 권한 기본안

현재는 고정된 역할 기본안을 실제 세션·견적/기준정보 API에 연결했다. 관리자 권한 편집 UI는 미구현이다. DB membership의 역할·활성 상태를 매 요청 확인한다.

| 액션 | 관리자 | 작성자 | 승인자 | 조회자 |
|---|---|---|---|---|
| 견적 편집·제출 | 허용 | 허용 | 거부 | 거부 |
| 승인 | 허용 | 거부 | 허용 | 거부 |
| 원가 조회 | 허용 | 허용 | 허용 | 거부 |
| 고객 출력 | 허용 | 허용 | 허용 | 거부 |
| 시스템 관리 | 허용 | 거부 | 거부 | 거부 |
| 일반 견적 조회 | 허용 | 허용 | 허용 | 허용 |
| 거래처·현장 등록 | 허용 | 허용 | 거부 | 거부 |

조회자 상세 응답에는 고객용 계산 DTO만 포함하며 원가 입력·마진은 제외한다. 현재 승인자의 화면은 견적 목록과 합계 확인까지만 지원한다. 승인 서비스와 허용 보고서는 후속 구현이다. 역할과 액션 매핑은 관리자 설정 가능 구조로 확장한다. 고객 외부 링크에는 직원 역할을 부여하지 않고 별도 토큰 접근 경계를 둔다.
