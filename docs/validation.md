## 2차 구현 — 인증·DB 저장

- 추가 설치: Better Auth / 공식 Drizzle 어댑터 1.7.18, Drizzle ORM 0.45.4, PGlite 0.5.15, pg 8.23.1, drizzle-kit 0.31.11, tsx 4.23.15.
- `test`: 4개 파일, 44개 테스트 통과. 기존 27개와 실제 SQL·인증·API·재시도·충돌·롤백·파일 DB 재개방 검증 포함.
- `typecheck`: 통과. 최종 `build`의 TypeScript 검사도 통과.
- 프로덕션 빌드: 통과. 견적 API·인증 API·직원 작업 화면·계정 보안 페이지 생성 확인.
- PGlite 테스트 DB에 최초 SQL 마이그레이션 적용 성공. 초기 인증 ID 기본값 누락은 SQL·스키마 snapshot 수정 후 재검증했다.
- TOTP 등록, 2차 인증 전 자료 접근 차단, 복구 코드 로그인, DB 기반 로그인 횟수 제한을 HTTP 핸들러로 검증했다.
- 원가 응답 제한은 실제 인증된 조회자 세션으로 확인했다. 비활성 membership의 기존 세션도 접근이 거부된다.

샌드박스에서 drizzle-kit/tsx가 사용자 정보 조회 제한으로 실패했다. 최초 마이그레이션 생성은 승인된 실행으로 완료했으며 추가 생성은 승인 거절 후 SQL을 직접 보완했다. 초기 관리자 및 로컬 업무 DB를 만드는 setup 실행도 승인되지 않아 `.env.local`·초기 관리자 파일·업무 DB는 생성하지 않았다. 격리 테스트 DB 검증과 이 초기 설정은 구분한다.

로컬 브라우저의 로그인→입력→저장 전체 상호작용, 실제 PostgreSQL, 운영 설정, 백업 복원은 미검증이다. 전체 제품과 AT-01~16은 여전히 미완료다. 사용자 터미널의 setup 후 브라우저 검증을 이어가야 한다.
