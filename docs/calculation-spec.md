# 계산 명세 — 초기 지원 부분

정책 ID: initial-line-krw-v1. PRD 전체 계산 요구 중 일부만 구현했다.

| 항목 | 현재 규칙 |
|---|---|
| 입력 | 문자열, 음수 금지, 정수 12자리·소수 6자리 상한 |
| 수량 0 | 초안 계산은 허용. 제출 시 오류/경고 정책은 후속 구현 |
| 반올림 | HALF_UP / DOWN / UP 중 선택, 원 단위 |
| 단순 행 | 수량 × 판매단가를 원 단위 처리 |
| 상세 행 | 수량 × (자재+노무+경비 단가)를 원 단위 처리 |
| 상세 간접비 | 처리된 상세 행 합계 × 간접비율, 원 단위 처리 |
| 상세 이윤 | 처리된 상세 행 합계 또는 해당 합계+간접비를 기준으로 계산·원 단위 처리 |
| 할인 | 공급가액 기준 정액/정률, 원 단위 처리, 할인 전 금액 초과 금지 |
| VAT | 할인 후 공급가액 × 단일 세율, 원 단위 처리 |
| 예상 총원가 | 처리 전 행 원가 총합을 원 단위 처리 + 간접비 |
| 마진 | (공급가액−예상 총원가)/공급가액, % 소수 2자리; 공급가액 0은 null |

상세 공급가액의 행별 처리 합계와 원가 전체 처리값의 차이는 반올림으로 발생할 수 있다. 따라서 이윤 가산액과 예상 이익이 항상 같지는 않다. 이 정책을 명시적으로 적용하며 공종/전체 처리 모드는 아직 제공하지 않는다.

미지원: 목표금액 역산·조정행, 추가비용, 과세 혼합, 공종 단위 계산, 자릿수 관리자 설정, 단가 급변 경고. 지원하지 않는 정책을 완료 처리하지 않는다.

기준 예제: 5×185,000=925,000, VAT=92,500, 총액=1,017,500. 상세 원가 700,000+간접비 10%(70,000)+이윤 20%(간접비 포함 기준 154,000)=공급가액 924,000.
